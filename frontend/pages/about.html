About the Project

Integrated Online Examination Portal with OpenCV-Based AI-Assisted Proctoring

This production-grade major project was designed and built as a 7th Semester B.Tech Computer Science Capstone Project. It bridges full-stack web architecture with applied computer vision microservices to deliver reliable, secure, and privacy-conscious online testing.

Key Architecture Highlights
Full-Stack Web App

RESTful PHP backend with strict PDO queries, modular role authorization, and a responsive Bootstrap 5 client interface.

OpenCV Computer Vision

Flask microservice evaluating real-time webcam frames for multi-face presence, gaze shifts, and camera status.
